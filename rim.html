RIM

A 3D OpenGL renderer written in C++ with GLFW, GLAD and GLM.

View on GitHub

Live demo

RIM's renderer ported to WebGL: the same cube, shaders, texture and rotation as source/main.cpp.

Your browser doesn't support WebGL 2, so the demo can't run.

Clone & build

Paste this into a terminal. It clones the repo and runs ./build.sh:

git clone https://github.com/m-saliola/RIM.git && cd RIM && ./build.sh

Then launch it from the RIM folder (it loads shaders and textures from resources/):

./build/main

Requirements

  • A C++ compiler, git and cmake (3.10+)
  • Linux: GLFW, OpenGL and X11 dev packages, e.g.
    sudo apt install build-essential cmake libglfw3-dev libgl-dev libx11-dev
  • macOS: brew install cmake glfw
  • Windows: GLFW is bundled in lib/; run build.sh from Git Bash with MinGW
